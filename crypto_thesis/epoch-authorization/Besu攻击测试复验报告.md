# Besu 攻击测试复验报告

| 攻击/异常 | 防护点 | 结果 |
|---|---|---|
| 跨链令牌重放 | CAP2 签名绑定 chainId | 拒绝 |
| 跨合约令牌重放 | CAP2 签名绑定合约地址 | 自动测试拒绝 |
| 旧 Epoch 令牌 | 当前 Epoch 比较 | 真实链拒绝 |
| 用户密钥轮换后旧令牌 | userVersion 与 keyId | 真实链拒绝 |
| CAP1 送入链绑定验证器 | 必须存在 ChainBinding | 自动测试拒绝 |
| 未授权合约调用 | 合约 RBAC 与账户许可 | 合约测试拒绝 |
| 重复用户公钥指纹 | `_keyOwners` 唯一约束 | 合约测试拒绝 |
| RPC 不可用 | fail-closed | 自动测试拒绝 |
| 发行期间状态变化 | 签名前二次读取 | 自动测试拒绝 |

已执行攻击请求的错误接受数为 0。该表不覆盖控制 QBFT 法定多数、端点私钥被盗或链下策略仓库被完全攻陷。
