# Besu 受控故障测试报告

## 环境与方法

单机运行 4 个 Besu QBFT 验证节点和 1 个非验证 RPC 节点。测试停止 validator-4，观察共识进展，再恢复该节点；随后停止和恢复 RPC 节点。

## 结果

| 指标 | 结果 |
|---|---:|
| 故障前区块 | 220 |
| 单验证者停机后区块 | 224 |
| 故障期间新增区块 | 4 |
| 验证者恢复后区块 | 228 |
| RPC 中断是否观察到 | 是 |
| RPC 恢复后区块 | 236 |
| 最终复核区块/peerCount | 241 / 4 |

原始证据为 `blockchain/besu/fault-check.json`。结果仅证明此次受控环境中单验证者故障未阻断出块、RPC 可恢复，不构成吞吐量、延迟、跨主机网络或长期稳定性结论。
