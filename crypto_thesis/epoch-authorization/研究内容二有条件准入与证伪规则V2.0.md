# 研究内容二有条件准入与证伪规则V2.0

## 冻结比较对象

```text
Baseline-I = I*二分匹配 + 公共Epoch/CAP1/签名/Nonce验证
Proposed-C = C(P)祖先路径匹配 + 相同公共验证 + 节点签名扩展
```

Proposed-C实际消费`C(P)`：签发时命中唯一Cover节点，令牌绑定
`matched_node`与`cover_version`，验证时重新计算。两方案TTL均以同一规范区间
终点为上界，避免改变授权语义。

## 公平条件

两方案必须共享策略、`I*`、`policyDigest`、用户、Epoch、Ed25519、Nonce存储、
状态读取、TTL、请求序列、时间查询、缓存政策和运行环境。Baseline-I固定使用
二分查找；任何节点缓存实验都必须提供复杂度相当的区间缓存对照。

## 正式实验前冻结指标

1. 语义不一致、合法误拒、非法接受和拒绝码差异；
2. 匹配、签发、验证延迟及吞吐量；
3. 缓存命中率、缓存项、状态项和峰值内存；
4. CAP1字节数，明确Proposed-C当前增加48字节；
5. \(k,c\)、节点覆盖槽数及碎片率退化。

## 降级规则

出现无稳定收益、仅人为场景占优、同等区间缓存可复制收益、令牌/内存/状态开销
超过收益、真实工作负载持续更慢、高碎片使主要场景失效或协议未实际消费Cover
中的任一项，均应将`C(P)`降级为可选派生结构。结果出来前不允许改变规则。
