# 研究内容二V13答辩口径

1. **为何重跑？** 第一次正式运行存在实质性采集协议偏差，因此主动失效并保留原始
   数据。V13 重新预注册并从头采集，不混用旧数据。
2. **性能是否提升？** 没有证据支持 B1、C1 或 C(P) 具有稳定工程收益。主要差异
   不足 1 ms 左右且置信区间跨 0。
3. **为何实验仍有价值？** 它证明在公平强基线下，局部表示优化被真实链读取成本
   主导，并为协议贡献划定诚实边界。
4. **核心贡献是什么？** 真实 QBFT 链上的授权状态锚定、CAP2 完整绑定、共享
   Nonce、多 Verifier 一致性、角色治理和 Fail-Closed。
5. **是否证明绝对安全？** 否。结论限定于代码、测试、真实链实验和规定故障模型。
6. **C(P)如何定位？** 可选派生执行 IR、消融和证伪对象，不作为核心优越方案。
