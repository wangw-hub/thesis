# 研究内容二 V2 可能质询与回答

## 是否存在伪重复？

主要推断以 `workload_id x seed x repetition` 的 2,430 个完整配对运行单元为
基础。请求级记录只用于运行内聚合和完整性检查。

## 为什么链读取占比接近 99%？

协议要求每次授权请求读取并复核真实链状态。隔离的 RPC/链读取路径是公共开销，
其量级远高于微秒级策略匹配，因此主导端到端时延。

## 负面结果是否削弱论文？

负面结果限制了 C(P) 的性能主张，但强化了研究边界：在强 I* 基线和完整安全
检查下，派生结构没有不可复制优势。论文贡献据此收敛到可审计授权闭环。

## 为什么不删除首次正式数据？

首次数据作为不可变的方法学审计证据保留并标记
`INVALIDATED_PROTOCOL_DEVIATION`，禁止用于性能结论。
