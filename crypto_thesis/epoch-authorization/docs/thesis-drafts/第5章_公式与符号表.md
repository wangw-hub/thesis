# 第5章公式与符号表

| 符号 | 含义 |
|---|---|
| \(I^*\) | 非连续时间策略唯一规范区间表示 |
| \(C(P)\) | 由 \(I^*\) 确定性派生的层次覆盖执行IR |
| `policyDigest` | 绑定 \(I^*\) 规范序列化的策略摘要 |
| \(R\) | 链上资源状态元组 |
| \(U\) | 链上用户状态元组 |
| CAP2 | 完整绑定当前链、合约、资源与用户状态的能力结构 |
| \(B\) | CAP2规范化签名字节 |
| \(\sigma\) | Issuer的Ed25519签名 |
| `stateVersion` | 资源状态单调版本 |
| `userVersion` | 用户状态/密钥单调版本 |
| `nonce` | 能力一次性消费标识 |

正文公式包括资源状态元组、用户状态元组和CAP2规范签名关系，共3组。
