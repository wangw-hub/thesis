# 研究内容二 V2 正式实验结果摘要

修正后的正式重跑在五节点 Besu QBFT 联盟链上完成，共覆盖 108 个因素配置、
324 个含随机种子的配置、9,720 个运行级重复、77,760 条授权请求和 233,280
次真实链读取。完整性审计未发现缺失配对、重复主键、PILOT_ONLY 混入、旧失效
数据混入、链标识错误或合约地址错误。

B0、B1、C0、C1 的运行级端到端时延中位数分别为 196.128 ms、196.583 ms、
198.682 ms 和 198.939 ms。四组主要配对比较的 95% Bootstrap 置信区间均跨
越零，未形成稳定的工程收益。热点局部性确实提高了缓存命中率，但没有稳定转化
为端到端时延改善。真实链读取占端到端中位时延的 98.66%-98.80%，并发度是
主要性能因素。

因此，C(P) 的定位冻结为由 I* 确定性派生的可选执行 IR 和证伪对象，不构成
研究内容二的核心性能贡献。研究内容二的主要贡献应表述为真实联盟链上的状态
锚定、CAP2 完整绑定、共享原子 Nonce、多验证器一致性及依赖故障下的
Fail-Closed 授权闭环。
