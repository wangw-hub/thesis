# 研究内容二 V2 答辩口径

1. 为什么重跑：首次正式运行存在链读取、局部性、吞吐和缓存指标定义偏差，
   已永久标记失效，未用于论文性能结论。
2. 如何保证重跑有效：先修复协议并新增自动测试，再冻结 V13 预注册；正式
   数据使用独立目录、独立 Nonce 命名空间和完整自然配对键。
3. 为什么时延高于旧结果：V13 对每个请求执行并记录三次真实链状态读取，旧
   运行没有完整覆盖该协议边界，二者不可直接比较。
4. C(P) 是否更快：没有稳定证据。主要配对置信区间均跨零，C(P) 不构成核心
   性能贡献。
5. 缓存是否有效：热点负载提高命中率，但在完整链读取与安全检查开销下没有
   形成稳定端到端收益。
6. 核心贡献是什么：真实五节点 QBFT 上的链状态锚定、CAP2 全字段绑定、共享
   Nonce、多验证器一致性和 Fail-Closed 行为。
