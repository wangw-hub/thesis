# 研究内容二V13正式实验结果摘要

V13 是研究内容二唯一有效的正式性能证据。其包含 108 个因素配置、324 个含 seed
配置、9,720 个运行块、77,760 条请求和 233,280 条真实链读取记录，完整性、配对、
污染和安全审计均通过。

B0、B1、C0、C1 的运行级端到端中位数分别为 196.128、196.583、198.682 和
198.939 ms。四组主要配对差异均很小，均值差的 95% 运行级 Bootstrap 置信区间
均跨 0，未形成稳定工程优势。链读取占时延 98.66%-98.80%，并发度是主要影响
因素。碎片率增加局部匹配成本，热点提高缓存命中率，但两者均未改变链读取主导的
端到端结论。

研究内容二的核心成果是链状态锚定、CAP2 完整上下文与版本绑定、共享原子 Nonce、
多 Verifier 一致性和依赖故障下的 Fail-Closed。C(P) 最终定位为可选派生 IR、
消融和证伪对象。
