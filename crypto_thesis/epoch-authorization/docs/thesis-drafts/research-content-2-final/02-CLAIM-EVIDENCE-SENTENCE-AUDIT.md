# Claim-Evidence Sentence Audit

| Claim family | Evidence class | Wording decision |
|---|---|---|
| Chain and contract identity | deployment and frozen interface | factual |
| CAP2 binding | code, interface, attack tests | supported for frozen implementation |
| Replay rejection | SQL uniqueness and concurrency tests | conditional, never absolute |
| Fail-Closed | controlled fault evidence | supported for tested faults |
| Method semantics | V13 semantic audit | no unexpected difference |
| Cache benefit | run-level paired Bootstrap | not supported |
| C(P) superiority | protocol and paired evidence | refuted |
| Arbitrary-scale performance | none | prohibited |

No sentence converts tests into a formal proof or a five-node result into a
general deployment claim.
