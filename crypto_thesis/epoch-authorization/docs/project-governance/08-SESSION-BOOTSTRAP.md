# Session Bootstrap

Before editing code, configuration, evidence, or thesis text:

1. Read root `AGENTS.md`.
2. Read this directory's Constitution, Current State, Risks and Hard Stops, and Next Action.
3. Check Git HEAD, worktree status, and relevant evidence paths.
4. Identify the affected research content and the thesis claim served.
5. Check that no active hard stop forbids the action.
6. Confirm the allowed modification scope and frozen assets.
7. Produce the required test, raw evidence, report, and Git-freeze plan.
8. Execute only after these checks; never infer completion from chat history.
9. On completion, update Current State, Decision Log, Claim-Evidence Matrix, Experiment Registry, Risks, Next Action, Source-of-Truth Index, and `project-state.json` as applicable.

Internal task logs should record the research content, claim, completion state, dependency evidence, asset impact, evidence output, and drift check. Plans never become results merely because they were written.
