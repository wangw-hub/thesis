# 第四章公式与符号一致性检查

| 检查项 | 结论 |
|---|---|
| 时间域 | 统一为 \(\mathcal D=[t_0,t_0+U\Delta)\) |
| 离散域 | 统一为 \(T=\{0,\ldots,U-1\}\) |
| 区间边界 | 全文使用半开区间 \([l,r)\) |
| 原始规模 | \(n\) 为原始区间数 |
| 规范规模 | \(k=|I^*|\) |
| 覆盖规模 | \(c=|C(P)|\) |
| 允许槽数 | \(A=|S(P)|\) |
| 摘要输入 | \(B(P)=Serialize(t_0,\Delta,U,I^*)\)，不含 \(C(P)\) |
| 摘要 | \(pd=SHA256(B(P))\) |
| 总时间 | \(O(n\log n+c)\)，序列化的 \(O(k)\) 被 \(k\le n\) 吸收 |
| Cover上界 | 仅写宽松上界 \(O(k\log U)\)，不写任意策略 \(O(\log U)\) |
| 碎片下界 | 独立分量至少 \(\Omega(k)\) 表示单元 |
| 非2次幂U | 概念容量为 \(L\)，有效节点不得越过 \(U\) |

## 已纠正的不一致

早期《论文实施蓝图V1.0》的部分伪代码曾把摘要写成对层次覆盖序列化。冻结技术设计、`serialize.py`、`compiler.py`及摘要性质测试均表明实际NTP1序列化对象为 \(I^*\)。本章采用冻结实现，避免执行IR变化导致策略摘要变化。
