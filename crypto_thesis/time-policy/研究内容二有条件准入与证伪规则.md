# 研究内容二有条件准入与证伪规则

## 1. 准入结论

依据2026-07-28用户转交的书面导师审核意见，研究内容一获得“原则认可、附条件通过”。允许进入研究内容二的技术设计和最小原型，但不得预先宣称双表示具有系统优势。

## 2. 冻结接口

```text
I*            主表示：唯一策略语义、NTP1输入、policyDigest基础、普通成员判断
C(P)          派生执行IR：由I*确定性生成，不参与policyDigest
policyDigest  绑定(t0, Delta, U, I*)的稳定策略标识
```

第五章必须明确说明哪个协议步骤读取 \(I^*\)、哪个步骤消费 \(C(P)\)，以及节点标识如何进入授权状态、令牌或验证流程。

## 3. 强基线

| 方案 | 时间策略表示 | 授权执行方式 |
|---|---|---|
| Baseline-I | 仅使用 \(I^*\) | 区间匹配后执行授权 |
| Proposed-C | 使用 \(I^*+C(P)\) | 基于层次节点执行授权 |

两种方案必须共享相同策略语义、授权规则、密码组件、联盟链环境、工作负载和测量流程，不得通过弱化Baseline-I获得正面结果。

## 4. 最低评价指标

1. 授权状态或链上记录数量；
2. 令牌、授权记录及交易负载大小；
3. 授权签发与验证延迟；
4. 策略更新涉及的对象或状态数量；
5. 可适用时的缓存复用、节点继承或聚合次数；
6. 不同时间域规模、覆盖率和碎片率下的额外开销；
7. 失败、退化和仅 \(I^*\) 更优的场景。

## 5. 可证伪判定

以下任一情况出现时，不得继续把 \(C(P)\) 作为论文主要贡献：

1. 第五章协议没有实际消费层次节点标识；
2. \(C(P)\) 仅增加转换或存储开销，没有带来可测量协议价值；
3. 仅使用 \(I^*\) 的方案在相同语义下更简单且综合指标不劣；
4. 所谓收益仅来自不公平实现、不同安全假设或不同测量流程；
5. 收益只在刻意选择的有利策略中出现，且无法说明适用边界。

触发后执行：

```text
C(P)降级为可选辅助表示
第四章删除“核心执行表示”含义
第五章按真实结果报告Baseline-I更合理的场景
全文创新总结不再把层次接口列为已验证贡献
```

## 6. 最终关闭门槛

研究内容一只有在第五章完成上述强基线对照、报告正负结果并确定 \(C(P)\) 的最终地位后，才可由“附条件通过”转为“最终关闭”。
