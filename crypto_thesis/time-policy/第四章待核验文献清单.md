# 第四章待核验文献清单

本清单仅定义检索任务，不构造未核验参考文献。正文中的占位符在完成原文核验前不得替换为正式编号。

| 位置 | 需要的文献类型 | 核验重点 | 建议检索词 |
|---|---|---|---|
| 4.1 非规范区间问题 | 区间并集、区间规范化或事件区间处理的教材/论文 | 是否明确给出排序合并及复杂度 | interval union canonicalization, merge overlapping intervals |
| 4.1/4.3 层次覆盖 | 线段树规范分解、dyadic interval decomposition的权威资料 | 最大对齐覆盖、节点数上界及应用语境 | dyadic interval decomposition, canonical segment tree cover |
| 4.2/4.3 时间离散化 | 时间访问控制或时态授权模型论文 | 半开区间、粒度、周期/非连续时间约束的定义 | temporal access control, time interval authorization |
| 4.2/4.3 规范序列化 | 确定性/规范编码标准或论文 | 字段唯一编码、字节序、哈希输入稳定性 | deterministic serialization, canonical encoding |
| 4.6 性质测试 | Hypothesis或property-based testing的官方/同行评议资料 | 性质测试能支持什么、不能证明什么 | property-based testing software verification |
| 4.6 Bootstrap | 统计方法教材或同行评议资料 | 百分位Bootstrap置信区间的适用条件 | percentile bootstrap confidence interval |
| 4.8 层次授权动机 | 层次密钥分配、树式授权或时间树相关论文 | 层次节点如何被授权协议消费，不得反推本章已有收益 | hierarchical key assignment, tree-based temporal authorization |

## 核验规则

1. 优先选择原始论文、标准、正式教材和官方技术规范。
2. 必须阅读全文或至少核验定义、算法和结论所在页，不以搜索摘要代替。
3. 记录作者、标题、来源、年份、卷期页码、DOI/稳定链接及对应正文位置。
4. 文献只能支撑其明确讨论的事实，不得用于证明本项目的实验结论。
5. 在文献未完成核验前，研究内容一不能达到“所有正式引用均已核验”的退出条件。
