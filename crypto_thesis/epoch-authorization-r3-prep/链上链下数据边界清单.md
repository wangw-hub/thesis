# 链上链下数据边界清单

| 数据 | 位置 | 原因 |
|---|---|---|
| resourceId/userId 的 Keccak-256 | 链上 | 固定长度索引 |
| owner/account 地址 | 链上 | 权限判断 |
| policyDigest、Epoch、状态与版本 | 链上 | 共识状态和令牌失效 |
| 状态迁移事件 | 链上 | 审计 |
| 规范区间 `I*`、Cover `C(P)` | 链下 | 避免策略细节和可变执行结构上链 |
| Ed25519 私钥、用户私钥 | 链下 | 秘密不得上链 |
| CAP2 与 Nonce 消费状态 | 链下 | 短期凭据和高频原子消费 |
| 文件、密文与元数据正文 | 链下 | 本阶段不处理存储层 |

链上摘要不证明链下内容可用；联盟链共识不提供数据机密性；链下 Nonce 后端在多 Verifier 部署前必须替换为共享原子存储。
