# Recovery Disposition V1

The closed vocabulary is `CONSISTENT`, `AUTO_RECOVERABLE`,
`RETRYABLE_TRANSIENT`, `MANUAL_RECONCILIATION_REQUIRED`,
`FAIL_CLOSED_MISSING_OBJECT`, `FAIL_CLOSED_CORRUPT_OBJECT`,
`FAIL_CLOSED_KEY_UNAVAILABLE`, `FAIL_CLOSED_CHAIN_UNAVAILABLE`,
`FAIL_CLOSED_DATABASE_UNAVAILABLE`, `IRRECOVERABLE_CONTENT_LOSS`,
`IRRECOVERABLE_KEY_LOSS`, `SUPERSEDED`, `ORPHANED_OBJECT`,
`ORPHANED_DATABASE_RECORD`, `UNKNOWN_TRANSACTION`, `CONFLICT`, and
`UNSUPPORTED`.

Only `CONSISTENT` enables material release. Automatic actions are bounded,
audited, and followed by full reconciliation.
