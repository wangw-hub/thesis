# 故障注入矩阵

| 点 | 位置 | 安全结果 |
|---|---|---|
| F1 | 临时创建后、写前 | 无正式对象；临时清理；重试通过 |
| F2 | 部分写后 | 无部分正式对象；临时清理；重试通过 |
| F3 | 完整写、flush 前 | 无正式对象；重试通过 |
| F4 | flush 后、fsync 前 | 无正式对象；重试通过 |
| F5 | fsync 后、发布前 | 无正式对象；重试通过 |
| F6 | 发布后、最终验证前 | 仅完整对象可见；调用失败；重试幂等 |
| F7 | 最终验证后、返回前 | 完整对象保留；调用失败；重试幂等 |
| F8 | 已有对象检测 | 不错误返回成功；既存对象不变 |

故障钩子仅位于 `storage.testing`，正式 put 不暴露确定故障点。
