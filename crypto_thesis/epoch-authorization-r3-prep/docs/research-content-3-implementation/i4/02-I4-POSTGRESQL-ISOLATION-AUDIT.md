# I4 PostgreSQL隔离审计

结论：`PASSED`。

- 正式集群：`16/main`，端口5432，PID 52520；创建前后PID与启动时间不变。
- 正式集群三份配置SHA-256创建前后完全一致。
- 新集群：`16/r3_i4`，端口55432，PID 364386。
- 新集群仅监听`127.0.0.1:55432`；从Windows直连`192.168.6.133:55432`失败。
- 新旧数据目录、配置目录、PID、端口均不同。
- 新角色和数据库仅存在于新集群；正式集群无新角色。
- 正式`epoch_auth`数据库不存在`r3_control` Schema。
- 新数据库初始public表数为0，不含研究内容二业务表。
- Windows仅通过SSH隧道`127.0.0.1:65432`连接。
- 远程秘密文件不回显；本地pgpass位于仓库外且ACL限制访问。
- 未查询研究内容二业务表、Nonce或授权记录。

接受的环境事实：正式集群自身仍监听其冻结地址；本任务没有改变该既有配置。
I4新集群严格loopback-only。
