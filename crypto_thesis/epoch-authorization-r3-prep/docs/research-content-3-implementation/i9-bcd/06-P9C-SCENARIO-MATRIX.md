# P9-C Frozen Scenario Matrix

The eight scenarios are LOCAL_READ, LOCAL_IPFS, HEADER_RESTORE, BODY_RESTORE,
CORRUPT_RESTORE, KUBO_UNAVAILABLE, CID_MISMATCH, and BOTH_MISSING. Each uses
explicit seeds 301 and 302, for 16 total runs. Final evidence must use real or
controlled system state rather than a mock return.
