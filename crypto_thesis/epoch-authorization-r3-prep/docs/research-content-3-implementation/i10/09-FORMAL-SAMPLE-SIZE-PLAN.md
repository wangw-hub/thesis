# Formal Sample Size Plan

The minimum sufficient plan has 29 configurations, 5 measured repetitions per configuration, 145 measured RUNs, 29 per-configuration warmups, 6 environment warmups, and 180 total planned RUNs including warmups. Estimated nominal duration is 4 hours with a 2–8 hour engineering range. `POWER_ANALYSIS_NOT_JUSTIFIED`: this is a bounded engineering precision plan and acceptance-proportion design, not a population power claim.
