# Formal Statistical Plan

The unit is RUN. Report n, mean, SD, median, IQR, and extrema; use 10,000-sample percentile bootstrap 95% CIs within pre-registered blocks; report median differences, positive-duration ratios on the log scale, and Cliff's delta where appropriate. Holm correction is used within each RQ family. Assumptions are checked descriptively; no unregistered subgroup, stopping, p-value, or favorable metric may be introduced.
