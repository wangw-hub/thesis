# 测试计划

1. **规范向量：** JCS、摘要、签名域、HPKE RFC向量、AEAD/KW官方向量、跨语言字节一致。
2. **负向密码测试：** nonce重复守卫、tag/AAD/字段/Body篡改、错误用户/密钥/套件。
3. **状态属性：** 随机合法/非法转换、版本单调、previousDigest连续、REVOKED终态。
4. **并发：** 同事件100并发、乱序版本、任务抢占、CAS失败、重复广播。
5. **恢复：** 每个持久化边界后崩溃；漏读补扫；receipt未知；数据库/RPC/存储中断。
6. **端到端：** upload→register→authorize→access→revoke→update→合法用户访问→撤销用户拒绝。

测试必须断言错误码和审计记录；任何依赖未知均fail-closed。正式实验前单元/集成/故障注入分层运行，并保存版本、配置、seed、原始输出和SHA-256。本轮不运行测试。
