# 安全与撤销边界

攻击者可读链与链下密文、持有旧 CAP2/Header/KEK、重放事件、替换或删除存储对象并诱发 RPC/数据库/代理故障。系统依赖标准原语安全、发行者签名密钥与用户私钥未泄露、授权服务正确执行、QBFT未超过容错阈值。

前瞻性撤销仅保证：确认后的新授权状态不再为撤销用户签发或封装新的有效访问材料，且客户端拒绝旧 epoch、旧版本和未锚定 Header。它不追回已经获得的明文、CK、旧 epoch 材料或本地缓存，也不解决用户共享私钥、终端恶意软件、内存窃取、管理员恶意、所有副本不可用或根密钥泄露。

存储方只承担字节保存/返回；完整性由摘要、AEAD与签名验证，可用性由 pin、复制和监测另行提供。详见 [安全论证计划](17-SECURITY-ARGUMENT-PLAN.md)。
