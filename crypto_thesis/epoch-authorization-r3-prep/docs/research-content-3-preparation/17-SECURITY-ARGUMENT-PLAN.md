# 安全论证计划

第一层引用标准性质：AEAD机密性/完整性、HPKE接收者封装、SHA-256抗碰撞假设、发行者签名不可伪造。RFC 9180 Base模式不认证发送者，故签名是系统必需组件。

第二层证明组合不变量：规范化摘要唯一输入、链/资源/策略/epoch绑定、版本单调、previousDigest链、幂等更新、旧版拒绝和撤销后不释放未来材料。每条论证列明依赖假设与反例。

第三层只做实验反证：字段篡改、错误Body/用户、旧Header/epoch、重复/漏读/乱序事件、重启以及DB/RPC/存储故障。测试通过不升级为原语安全证明。

论证结果映射至 [不变量](12-SYSTEM-INVARIANTS.md)、[主张证据矩阵](18-CLAIM-EVIDENCE-MATRIX.md)与 [测试计划](22-TEST-PLAN.md)。
