# Formatting Authority Map

- OFFICIAL_TEMPLATE：未找到学校官方学位论文 DOCX/DOTX 模板。
- OFFICIAL_FORMAT_GUIDE：未找到学校官方撰写/排版规范文档。
- HISTORICAL_EXAMPLE：`开题报告表-王威-1 (2).docx`（电子科技大学，专业学位研究生学位论文开题报告表；提供学校名称、学号、姓名、学院、专业学位类别与指导教师字段）。
- USER_DRAFT：`THESIS-INTEGRATED-MASTER-DRAFT-V1.md`（I14/I15 冻结候选）。
- NON_AUTHORITATIVE_REFERENCE：CONSERVATIVE_ACADEMIC_FORMAT_CANDIDATE（A4、宋体/Times New Roman、1.5 倍行距、三线表等通用候选设置）。
- FORMAT_AUTHORITY_GAP：字体/字号、标题层级、页眉页脚、页码体系、封面版式、GB/T 7714 版本、题注格式均需学校官方模板确认；详见 `OFFICIAL-TEMPLATE-GAP.md`。
