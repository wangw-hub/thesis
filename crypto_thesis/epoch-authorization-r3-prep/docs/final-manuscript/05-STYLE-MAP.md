# Style Map

FinalHeadingStyleMapV1（CONSERVATIVE_ACADEMIC_FORMAT_CANDIDATE，未对照官方模板）：
- 论文题目/封面：黑体 26pt（校名）、22pt（学位论文标题）、18pt（题目）；
- Heading 1（章）：黑体 16pt 居中，段前段后 24pt，新页开始；
- Heading 2：黑体 14pt；Heading 3：黑体 12pt；Heading 4：黑体 12pt 加粗；
- Normal 正文：宋体 12pt（小四）/ Times New Roman，1.5 倍行距，首行缩进 2 字符；
- Caption/Table Caption/Algorithm Caption：宋体 10.5pt 加粗居中；
- Reference：宋体 10.5pt，悬挂缩进 2 字符；
- Equation：居中 + 右对齐编号（章内连续 (4-1)…(5-3)）；
- Algorithm/代码：Consolas 9pt 灰色边框；Table：10.5pt 三线表候选。
