# 第一部分 研究内容一创新闭环分析

## 1.1 严格创新性审查

当前方法包含五个步骤：

```text
时间解析 → 区间规范化 → 层次覆盖 → 规范序列化 → 匹配与评价
```

逐项判断如下。

| 内容 | 准确分类 | 能否单独作为创新 | 审稿判断 |
|---|---|---:|---|
| 区间排序 | 普通数据结构操作 | 否 | 标准排序 |
| 相交/相邻区间合并 | 已有区间算法 | 否 | 经典区间合并 |
| 二进制层次区间分解 | 已有算法思想 | 否 | 与线段树规范分解、二进制区间分解相近 |
| SHA-256策略摘要 | 工程操作 | 否 | 标准哈希应用 |
| 时间解析和Epoch映射 | 工程优化 | 否 | 必要但不新 |
| 规范序列化规则 | 方法改进 | 部分 | 若证明同义策略产生相同字节表示，可作为系统方法组成部分 |
| 语义IR与执行IR分离 | 编译方法改进 | 是，有限度 | 将规范区间作为语义表示、层次节点作为执行表示，职责清楚 |
| 输出敏感复杂度与退化边界 | 理论性质 | 是，有限度 | 明确否定任意集合`O(log U)`，是可信贡献的重要部分 |
| 成本感知的双表示评价 | 方法与实验贡献 | 是 | 不预设层次覆盖必然更优，识别适用区间和失败区域 |
| 自动性质验证及可复现实验 | 工程研究贡献 | 是 | 支撑论文可信度，不是算法原创 |

### 严格结论

“Normalize + dyadic cover”本身不足以被表述为新算法。如果第四章只写“使用区间合并和线段树压缩时间策略”，创新性偏弱，容易被评为常规工程实现。

但它可以形成专业硕士论文的一个完整贡献章节，条件是：

1. 不宣称发明区间合并或层次分解；
2. 将贡献定位为**面向非连续时间约束的一套确定性策略编译方法**；
3. 明确区分语义中间表示和层次执行表示；
4. 给出语义保持、确定性、唯一序列化和复杂度边界；
5. 通过实验回答层次覆盖何时有效、何时退化、是否值得使用；
6. 普通区间列表必须作为强基线，不能只与时间点枚举比较。

## 1.2 强化后的核心贡献

### 问题

细粒度时间策略可能由无序、重复、重叠、相邻和嵌套区间构成。同一语义可以有多种输入写法，直接枚举时间点会产生与允许时间槽数量成正比的表示，而未经规范化的区间列表又不能生成稳定的语义标识。

### 方法

设计一个两级中间表示的确定性编译流程：

1. **语义IR `I*`：** 将原始策略转换为唯一的、互不重叠且互不相邻的有序区间集合。
2. **执行IR `C(P)`：** 将每个规范区间分解为唯一的最大二进制对齐区间集合。
3. **规范编码：** 对版本、时间域、粒度和语义IR执行无歧义序列化，得到稳定摘要；执行IR用于层次匹配和性能评价。

这里建议将策略摘要建立在`I*`上，而不是建立在`C(P)`上。原因是`I*`直接表达策略语义，并且不依赖具体层次覆盖实现；以后即使优化Cover算法，同一策略的摘要也不会变化。

### 理论性质

- 语义保持：原始策略、规范策略和层次覆盖表示同一允许时间集合。
- 确定性：输入顺序、重复区间和等价拆分不影响`I*`。
- 规范性：同一时间域、粒度和策略语义生成唯一字节表示。
- 输出敏感复杂度：总时间为`O(n log n+c)`，其中`n`为原始区间数，`c`为实际输出节点数。
- 诚实边界：单规范区间的层次覆盖为`O(log U)`；`k`个规范区间为`O(k log U)`上界；孤立碎片最坏至少为`Ω(k)`。

### 实验验证

- E1测量枚举、普通区间列表和层次覆盖的表示大小及运行开销。
- E2用穷举、小规模全检查和Hypothesis随机测试验证语义等价、确定性和边界行为。
- 同时报告正面区间和退化区间，不预设层次覆盖在所有指标上胜出。

## 1.3 最终贡献表述

建议论文将本章贡献表述为：

> 提出一种面向非连续时间约束的确定性规范化编译方法。该方法采用语义中间表示与层次执行表示相分离的两级结构，消除原始策略中的顺序、重复、重叠和等价拆分差异，并将规范区间转换为最大二进制对齐覆盖。本文证明了编译过程的语义保持性、确定性和规范编码唯一性，给出输出敏感复杂度及高碎片策略下的退化边界，并通过可复现实验量化其相对时间点枚举和普通区间列表的适用范围。

不得写成：

> 本文提出全新的区间压缩算法，可将任意非连续时间策略压缩为对数大小。

# 第二部分 数学模型

## 2.1 时间模型

### 2.1.1 连续时间与离散时间槽

设研究覆盖的真实时间范围为：

```math
\mathcal{D}=[t_0,t_0+U\Delta)
```

其中：

- `t_0`为时间域起点，统一表示为UTC时间；
- `Δ>0`为最小时间粒度，例如1分钟；
- `U∈N+`为时间槽总数。

定义Epoch映射：

```math
\phi(t)=\left\lfloor\frac{t-t_0}{\Delta}\right\rfloor
```

当`t∈𝒟`时，有`φ(t)∈T`，其中离散时间域：

```math
T=\{0,1,\ldots,U-1\}
```

论文统一使用半开区间`[l,r)`。真实时间区间`[a,b)`离散化为：

```math
[\phi_{\mathrm{floor}}(a),\phi_{\mathrm{ceil}}(b))
```

输入层必须固定边界取整策略。默认规则为：开始时间向下取整、结束时间向上取整，以避免遗漏用户声明的时间范围；若业务要求严格内含，可配置相反规则，但同一实验中不可混用。

### 2.1.2 符号表

| 符号 | 含义 |
|---|---|
| `t_0` | 研究时间域的UTC起点 |
| `Δ` | 最小时间粒度 |
| `U` | 时间槽总数 |
| `T` | 离散时间域`{0,...,U-1}` |
| `L` | 覆盖树容量，`L=2^{⌈log₂U⌉}` |
| `h` | 二叉层次高度，`h=log₂L=⌈log₂U⌉` |
| `P` | 原始时间策略，由`n`个半开区间组成 |
| `n` | 原始区间数量 |
| `S(P)` | 策略`P`允许的时间槽集合 |
| `I*` | `Normalize(P)`输出的规范区间序列 |
| `k` | 规范区间数量，`k=|I*|≤n` |
| `D(j,s)` | 二进制对齐区间`[j·2^s,(j+1)·2^s)` |
| `C(P)` | 规范区间的最大二进制对齐覆盖 |
| `c` | 覆盖节点数量，`c=|C(P)|` |
| `B(P)` | 规范序列化结果 |
| `pd` | 策略摘要，`pd=SHA-256(B(P))` |
| `χ_P(x)` | 策略成员函数，允许时为1，否则为0 |

## 2.2 非连续时间策略

原始策略定义为区间多重序列：

```math
P=\langle[l_1,r_1),[l_2,r_2),\ldots,[l_n,r_n)\rangle
```

满足：

```math
0\le l_i<r_i\le U
```

原始输入允许：

- 任意顺序；
- 重复区间；
- 相交区间；
- 相邻区间；
- 嵌套区间。

策略语义不是区间序列本身，而是允许时间槽集合：

```math
S(P)=\bigcup_{i=1}^{n}\{x\in T\mid l_i\le x<r_i\}
```

成员函数为：

```math
\chi_P(x)=
\begin{cases}
1,&x\in S(P)\\
0,&x\notin S(P)
\end{cases}
```

空策略`P=⟨⟩`的语义为`S(P)=∅`。

## 2.3 规范策略

`Normalize(P)`输出：

```math
I^*=\langle[a_1,b_1),[a_2,b_2),\ldots,[a_k,b_k)\rangle
```

并满足：

1. 合法性：`0≤a_i<b_i≤U`；
2. 有序性：`a_i<a_{i+1}`；
3. 分离性：`b_i<a_{i+1}`，即规范区间不重叠且不相邻；
4. 极大性：任意两个规范区间不能在保持语义的情况下继续合并；
5. 语义保持：`S(I*)=S(P)`。

注意，题目中“`Normalize(P)=P`”应严格写成：

```math
S(Normalize(P))=S(P)
```

两者的数据结构通常并不相等，只有语义集合相等。

### 命题1：语义保持

对任意合法策略`P`：

```math
S(Normalize(P))=S(P)
```

证明要点：排序不改变并集；合并两个相交或相邻区间后，其并集与合并区间相同；逐步合并保持不变量。

### 命题2：确定性

给定固定的合法性规则、排序键和相邻区间合并规则，若：

```math
S(P_1)=S(P_2)
```

则：

```math
Normalize(P_1)=Normalize(P_2)
```

原因是有限整数域上一维集合的极大连续分量分解唯一。该命题比“相同输入顺序得到相同输出”更强，它覆盖乱序、重复和等价拆分。

## 2.4 二进制层次覆盖

为处理`U`不是2的幂的情形，定义：

```math
L=2^{\lceil\log_2 U\rceil}
```

构造根区间`[0,L)`的完全二叉层次。任意节点表示二进制对齐区间：

```math
D(j,s)=[j2^s,(j+1)2^s)
```

其中`s∈{0,...,h}`，`j`为非负整数。有效覆盖节点还须完全位于`[0,U)`。

对规范区间`I=[a,b)`，定义其规范覆盖`C(I)`为所有满足下列条件的节点：

1. `D(j,s)⊆I`；
2. `D(j,s)`的父节点不完全包含于`I`。

即`C(I)`由`I`内部的**最大二进制对齐区间**组成。

全策略覆盖为：

```math
C(P)=\bigcup_{I\in I^*}C(I)
```

为保证输出顺序唯一，节点按`start`升序、`size`降序排序；实际上最大覆盖节点互不重叠，按起点排序已经足够，第二排序键用于防御实现错误。

## 2.5 规范序列化

摘要应编码策略语义及解释环境：

```text
magic        : 4 bytes, "NTP1"
schema       : uint16
time_origin  : int64 UTC epoch seconds
granularity  : uint64 seconds
domain_size  : uint64
interval_cnt : uint32
intervals    : repeated (uint64 left, uint64 right)
```

编码要求：

- 固定大端字节序；
- 固定宽度无符号整数；
- 禁止浮点数；
- 禁止JSON对象作为摘要输入；
- `I*`必须先通过合法性检查；
- 所有实现使用同一Schema版本。

定义：

```math
B(P)=CanonicalSerialize(t_0,\Delta,U,I^*)
```

以及：

```math
pd=SHA\text{-}256(B(P))
```

### 命题3：可序列化唯一性

固定Schema后，若两个策略语义和时间解释环境相同，则其规范字节串相同：

```math
S(P_1)=S(P_2)
\land(t_0,\Delta,U)_1=(t_0,\Delta,U)_2
\Rightarrow B(P_1)=B(P_2)
```

反之，在不考虑哈希碰撞且编码解析无歧义的条件下，不同规范字段产生不同字节串。

# 第三部分 Algorithm 1正式设计

## 3.1 论文伪代码

### Algorithm 1: Non-contiguous Time Policy Compilation

```text
Input:
    P      raw interval sequence
    t0     UTC origin of the time domain
    Δ      slot granularity
    U      number of slots

Output:
    I*     canonical semantic interval representation
    C      canonical hierarchical cover
    B      canonical semantic byte representation
    pd     SHA-256 policy digest

Procedure POLICY-COMPILE(P, t0, Δ, U):
 1:  REQUIRE Δ > 0 AND U > 0
 2:  Q ← empty list
 3:  FOR each raw interval [start, end) IN P DO
 4:      [l, r) ← TO-SLOTS(start, end, t0, Δ)
 5:      REQUIRE 0 ≤ l < r ≤ U
 6:      APPEND [l, r) TO Q
 7:  END FOR
 8:
 9:  SORT Q BY (left ascending, right ascending)
10:  I* ← empty list
11:  FOR each [l, r) IN Q DO
12:      IF I* is empty OR last(I*).right < l THEN
13:          APPEND [l, r) TO I*
14:      ELSE
15:          last(I*).right ← max(last(I*).right, r)
16:      END IF
17:  END FOR
18:
19:  C ← empty list
20:  FOR each [l, r) IN I* DO
21:      APPEND all nodes from DYADIC-COVER(l, r) TO C
22:  END FOR
23:  SORT C BY (start ascending, size descending)
24:
25:  B ← CANONICAL-SERIALIZE("NTP1", schema, t0, Δ, U, I*)
26:  pd ← SHA-256(B)
27:  RETURN (I*, C, B, pd)
```

### Algorithm 1a: Dyadic Cover

```text
Input:
    l, r   slot endpoints satisfying 0 ≤ l < r ≤ U

Output:
    C_I    ordered maximal dyadic cover of [l, r)

Procedure DYADIC-COVER(l, r):
 1:  C_I ← empty list
 2:  WHILE l < r DO
 3:      remaining ← r - l
 4:      IF l = 0 THEN
 5:          aligned ← highestPowerOfTwoAtMost(remaining)
 6:      ELSE
 7:          aligned ← lowestSetBit(l)
 8:      END IF
 9:      size ← aligned
10:      WHILE size > remaining DO
11:          size ← size / 2
12:      END WHILE
13:      APPEND Node(start=l, size=size) TO C_I
14:      l ← l + size
15:  END WHILE
16:  RETURN C_I
```

第7行得到从`l`开始的最大对齐二进制块，第10-12行确保块不超过右边界。实现时使用整数位运算，不使用浮点对数。

## 3.2 时间复杂度

设：

- `n=|P|`；
- `k=|I*|`；
- `c=|C(P)|`；
- `b=|B|`为规范编码字节数。

### Parse / To-Slots

每个输入区间解析和映射一次：

```math
T_{parse}=O(n)
```

若解析ISO-8601字符串，其长度存在固定上限，可视为常数；否则应写成输入字符总数的线性复杂度。

### Normalize

Normalize由排序和线性扫描组成：

```math
T_{sort}=O(n\log n)
```

```math
T_{merge}=O(n)
```

因此：

```math
T_{normalize}=O(n\log n)
```

### Cover

每输出一个节点执行常数次整数操作：

```math
T_{cover}=O(c)
```

对单个规范区间，最大二进制覆盖节点数为`O(log U)`；对`k`个区间：

```math
c=O(k\log U)
```

但算法应按输出敏感形式报告`O(c)`，因为连续整域可能只有1个节点，而高度碎片策略可能有`Θ(k)`个节点。

若Algorithm 1第23行的节点天然按区间和起点生成，则无需再次排序，可省略该排序并在实现中断言有序，此时`T_cover=O(c)`。正式实现建议采用这一方式。

### Serialize

基于`I*`固定宽度编码：

```math
b=b_0+16k
```

其中`b_0`为固定头部长度，因此：

```math
T_{serialize}=O(k)
```

### Hash

SHA-256处理整个字节串：

```math
T_{hash}=O(b)=O(k)
```

### 最终复杂度

不进行冗余节点排序时：

```math
T(n,k,c)=O(n\log n+c+k)
```

由于`k≤n`，可简化为：

```math
T(n,c)=O(n\log n+c)
```

代入宽松上界：

```math
T=O(n\log n+k\log U)
```

首选论文表述是输出敏感的`O(n log n+c)`，第二个式子仅作为上界补充。

## 3.3 空间复杂度

| 数据 | 大小 |
|---|---:|
| 原始/离散区间`Q` | `O(n)` |
| 规范区间`I*` | `O(k)` |
| 覆盖节点`C` | `O(c)` |
| 规范字节串`B` | `O(k)` |
| 排序辅助空间 | 依赖实现，Python `sorted`通常为`O(n)`最坏辅助空间 |

保留所有输出时：

```math
S(n,k,c)=O(n+k+c)=O(n+c)
```

若允许原地排序和流式哈希，可以减少常数，但Python原型不以牺牲可读性为代价追求原地优化。

## 3.4 正确性证明

### Lemma 1：区间合并正确性

**陈述：** Algorithm 1第9-17行输出的`I*`满足：

```math
S(I^*)=S(P)
```

且区间有序、互不重叠、互不相邻。

**证明：**

排序只改变区间顺序，不改变并集。扫描过程中保持循环不变量：处理前`j`个排序区间后，`I*`表示这`j`个区间的并集，且已规范化。若新区间与最后区间分离，则追加不会产生重叠或相邻；若相交或相邻，则将二者替换为其凸并区间，其允许整数槽集合不变。归纳至所有区间后，语义保持且结构规范。证毕。

### Lemma 2：规范覆盖完整性

**陈述：** 对任意规范区间`I=[a,b)`，`DYADIC-COVER(a,b)`输出的节点两两不重叠，完全位于`I`内，且其并集等于`I`。

**证明：**

每次循环选择从当前`l`开始、长度不超过`r-l`的正二进制块，因此节点位于剩余区间内。加入节点后令`l←l+size`，故后继节点起点不小于前一节点终点，节点不重叠。每次`size≥1`，循环有限终止于`l=r`。所有节点首尾相接覆盖从初始`a`到`b`的全部槽，因此并集等于`I`。证毕。

### Lemma 3：规范序列唯一性

**陈述：** 对固定`t0、Δ、U`，语义等价策略生成相同`I*`和`B`。

**证明：**

有限整数线上的集合可唯一分解为极大连续分量；由Lemma 1，Normalize输出正是这些分量，因此语义等价策略生成同一有序`I*`。CanonicalSerialize使用固定字段顺序、固定宽度和固定字节序，是从字段元组到字节串的单射编码，故生成相同`B`。证毕。

### Lemma 4：层次覆盖规范性

**陈述：** 以“完全包含于目标区间且父节点不完全包含”为定义时，`C(I)`唯一。

**证明思路：**

层次树固定后，每个叶时间槽沿祖先路径存在唯一的最高节点仍完全包含于`I`。所有这类最大节点组成互不包含、互不重叠的前缀无关集合。任何完整覆盖若使用其子节点都不是最大覆盖；若使用其父节点则越出`I`。故最大节点集合唯一。

### Theorem：PolicyCompile正确性

**陈述：** 对任意合法输入`P、t0、Δ、U`，Algorithm 1终止并输出`I*、C、B、pd`，满足：

1. `S(P)=S(I*)=S(C)`；
2. 语义等价输入在相同环境下产生相同`I*、C、B、pd`；
3. 算法时间复杂度为`O(n log n+c)`，空间复杂度为`O(n+c)`。

**证明：**

终止性来自有限区间扫描和Cover循环中`l`严格增加。语义等价由Lemma 1和Lemma 2传递得到。唯一性由Lemma 3和Lemma 4得到；摘要确定性由确定性哈希函数得到。复杂度由第3.2和3.3节逐阶段求和得到。证毕。

哈希碰撞抗性不属于本算法正确性定理。论文只说明使用标准哈希得到固定长度标识，不证明SHA-256本身安全。

# 第五部分 测试体系

## 5.1 实现任务与验收

### Task 1：时间解析模块

- 输入：ISO-8601时间、`t0、Δ、U`、边界模式。
- 输出：合法半开槽区间`[l,r)`。
- 测试：UTC与带偏移时间等价；缺失时区拒绝；越界拒绝；开始不早于结束拒绝；粒度边界精确。

### Task 2：Normalize模块

- 输入：整数区间序列。
- 输出：有序、互斥、非相邻的`I*`。
- 测试：空、单区间、乱序、重复、重叠、相邻、嵌套、链式重叠；验证幂等性`N(N(P))=N(P)`。

### Task 3：Canonical Cover模块

- 输入：`I*、U`。
- 输出：最大二进制对齐节点`C`。
- 测试：节点对齐、节点不重叠、节点不越界、父节点非完全包含、叶集合等价。

### Task 4：Matcher模块

- 输入：时间槽及枚举/区间/层次表示。
- 输出：布尔值。
- 测试：对同一策略遍历小域，三种Matcher结果完全一致；测试`0`和`U-1`。

### Task 5：Digest模块

- 输入：`t0、Δ、U、I*`。
- 输出：规范字节串和32字节摘要。
- 测试：输入重排、重复和等价拆分摘要相同；任一语义槽变化摘要应变化；固定黄金向量跨运行一致。

### Task 6：自动化测试

- 输入：固定示例、随机策略、边界规模。
- 输出：pytest报告、覆盖率和失败最小反例。
- 测试方法：pytest + Hypothesis；CI中固定最大样例数和Deadline策略；性能实验不混入单元测试。

## 5.3 Hypothesis性质测试

随机生成：

- `U`取`1...4096`；
- 区间数`n`取`0...100`；
- 每个端点满足`0≤l<r≤U`；
- 输入随机打乱并随机插入重复区间。

必须验证的性质：

1. **语义等价**

```python
for x in range(U):
    assert raw_match(P, x) == interval_match(I_star, x)
    assert raw_match(P, x) == cover_match(C, x)
```

2. **幂等性**

```python
normalize(normalize(P)) == normalize(P)
```

3. **置换不变性**

```python
compile(P).bytes == compile(permutation(P)).bytes
```

4. **等价拆分不变性**

将`[a,b)`随机拆为`[a,m),[m,b)`，摘要不变。

5. **覆盖结构不变量**

- 每个`size`是2的幂；
- `start % size == 0`；
- 节点两两不重叠；
- 不存在两个兄弟节点可合并为仍在策略内的父节点。

6. **摘要稳定性**

同一规范输入重复编译，字节和摘要完全一致。

## 5.4 边界与规模测试

| 场景 | 策略 | 验证重点 |
|---|---|---|
| 连续全域 | `[0,U)` | 若`U`为2的幂，覆盖应为1个节点 |
| 非2幂全域 | `[0,U)` | 覆盖为`U`的二进制分解，不越出`U` |
| 单点碎片 | `[1,2),[3,4),...` | 节点数近似碎片数，不错误声称对数压缩 |
| 最大碎片 | 允许所有偶数槽或奇数槽 | 相邻槽无法合并，展示`Ω(U)`退化 |
| 单大区间 | `[1,U-1)` | 边界产生多个对齐块 |
| 大规模 | `U=10^6`，多组`n/k` | 编译时间、内存、无逐槽编译依赖 |
| 极大单区间数 | `n=10^5`可选压力测试 | 排序主导、内存行为 |

大规模正确性不应遍历全部`U`作为唯一验证。可结合随机查询、区间边界查询和小域穷举。

## 5.5 测试通过门槛

- 所有单元测试通过；
- Hypothesis至少运行10,000个策略样例，无语义反例；
- 小域`U≤16`可枚举的策略样本执行穷举检查；

- `U=10^6`实验不创建长度为`U`的Python布尔数组，枚举基线除外且须单独限制规模。

## 6.2 数据生成模型

### 固定随机种子

主实验使用：

```text
20260727, 20260728, 20260729
```

调试种子与正式种子分开。结果文件必须记录种子、代码提交、Python版本和配置哈希。

### 时间跨度

建议：

```text
U ∈ {10^3, 10^4, 10^5, 10^6}
```

这些值表示离散时间槽数量，不强绑定为分钟。若按分钟解释，`10^6`约为1.9年。

### 原始区间数量

```text
n ∈ {1, 4, 16, 64, 256, 1024}
```

对大`U`执行全组合；不合理组合如`n>U`按生成模型限制。

### 碎片率

定义语义占用槽数：

```math
A=|S(P)|
```

规范连续分量数为`k`。定义归一化碎片率：

```math
F=
\begin{cases}
0,&A=0\\
\frac{k-1}{A-1},&A>1
\end{cases}
```

有：

- `F=0`表示所有允许槽形成一个连续分量；
- `F=1`表示每个允许槽均彼此隔离。

实验目标档位：

```text
F ∈ {0, 0.25, 0.50, 0.75, 1.00}
```

生成器应以目标`k`和总允许槽数`A`构造策略，再随机拆分、重复和打乱形成原始`P`，从而区分“语义碎片度”和“输入冗余度”。

### 覆盖率

定义：

```math
\rho=A/U
```

取：

```text
ρ ∈ {0.01, 0.10, 0.50, 0.90}
```

碎片率与覆盖率共同决定策略结构，不能只改变区间数。

### 输入冗余度

为验证Normalize价值，定义原始区间数与规范区间数之比：

```math
R=n/k
```

设置：

```text
R ∈ {1, 2, 4, 8}
```

通过拆分、重叠、重复和嵌套制造等义但不同写法。

## 6.3 对比基线

### Baseline 1：时间槽枚举

- 表示：排序整数时间槽数组或固定宽度整数序列。
- 匹配：哈希集合`O(1)`期望时间，或排序数组二分；论文必须注明具体实现。
- 大小：与`A`线性相关。
- 注意：若使用Python `set`测内存，需同时报告逻辑编码字节和Python对象实际内存，不能混为一谈。

### Baseline 2：普通规范区间列表

- 表示：`I*`中的`k`对端点。
- 匹配：按左端点二分搜索，`O(log k)`。
- 这是最重要的强基线。在纯一维成员判断和存储上，它可能优于层次覆盖。

### Ours：最大二进制层次覆盖

- 表示：`c`个`(start,size)`节点。
- 匹配方案A：节点起点索引后查询；
- 匹配方案B：由时间槽生成至多`h+1`个祖先标识，并查哈希集合，`O(log U)`。
- 实验必须预先固定Matcher实现，避免为不同数据选择有利实现。

## 6.4 指标定义

### 表示长度

同时报告：

1. **元素数量：** `A、k、c`；
2. **规范编码字节：** 使用固定宽度无压缩二进制编码；
3. **Python驻留内存：** 使用统一工具测量完整数据结构深度内存。

不建议只报告`sys.getsizeof`顶层对象，因为它不包含嵌套对象。

### 压缩率

以枚举为基线：

```math
CR_{enum}=\frac{Bytes_{enum}}{Bytes_{method}}
```

以普通区间列表为基线：

```math
CR_{interval}=\frac{Bytes_{interval}}{Bytes_{cover}}
```

`CR>1`表示被比较方法更紧凑。若`CR_interval<1`，应如实说明Cover比区间列表更大。

也可报告节省率：

```math
Saving=1-\frac{Bytes_{method}}{Bytes_{enum}}
```

### 编译时间

- 从已解析整数区间开始计时，避免日期字符串解析干扰核心算法；
- 另设端到端时间包含解析；
- 每配置预热5次、正式重复30次；
- 使用`perf_counter_ns`，每轮重新复制输入，防止原地排序污染。

### 匹配时间

- 预生成相同查询集合，三种方法共享；
- 50%命中、50%未命中；
- 强制包含所有区间左右边界附近的查询；
- 报告单查询中位数、p95和吞吐。

### 内存

- 编译峰值内存；
- 最终表示驻留内存；
- 枚举基线在`U=10^6、ρ=0.9`可能很大，应设资源上限并记录OOM为结果，而不是静默跳过。

### 4.5 复杂度分析

逐阶段列出：

| 阶段 | 时间 | 额外空间 |
|---|---:|---:|
| Parse | `O(n)` | `O(n)` |
| Sort | `O(n log n)` | 实现相关，Python最坏`O(n)` |
| Merge | `O(n)` | `O(k)` |
| Cover | `O(c)` | `O(c)` |
| Serialize/Hash | `O(k)` | `O(k)` |
| 总计 | `O(n log n+c)` | `O(n+c)` |

必须讨论：

- `c=O(k log U)`只是上界；
- 连续对齐区间可为1个节点；
- 最大碎片时`c=Ω(k)`；
- 不存在任意策略无条件`O(log U)`压缩；
- 普通区间列表可能比层次覆盖更紧凑。
